STEP 1 · SCREENER
Build the candidate universe from S&P 500
~50 large-cap stocks ranked by composite score
▾
Composite Ranking Score (0–1)
Growth · 40%
Rev YoY (cap 50%)
Momentum · 30%
% above 200DMA (cap ±30%)
Quality · 30%
Gross margin (cap 70%) + positive earnings
Missing data gets 30% of the weight (not zero) — preserves optionality on names with partial coverage.
HARD FILTERS (before scoring)
Market cap ≥ $10B  ·  ADV ≥ $50M
UNIVERSE
S&P 500 + common sector ETFs (SMH, XLV, EFA, TLT…)
PRIORITY FLAGS (non-blocking)
below_micro_cap_floor · valuation_stretch · low_liquidity · negative_momentum
OUTPUT
Top 50 candidates with: ticker, sector, score, fwd_pe, rev_growth_yoy, gross_margin
↓ top 50 candidates passed to momentum gate
STEP 2 · MOMENTUM PRE-FILTER
Bucket every candidate: clean / extended / parabolic
Deterministic Python — no LLM, runs from yfinance cache in <2s
▾
🟢 CLEAN
Primary buy candidates
  • RSI < 65
  • ≤ 30% above 200DMA
  • ≤ 5 consecutive up days
→ eligible for STRONG_BUY or BUY
🟡 EXTENDED
One flag triggered
  • RSI 65–79
  • 30–49% above 200DMA
  • 6–9 up days in a row
→ WAIT-FOR-COOLING only
🔴 PARABOLIC
Dropped entirely
  • RSI ≥ 80
  • > 50% above 200DMA
  • ≥ 10 consecutive up days
→ LLM never sees these
Metrics used: RSI(14), % vs 200DMA, consecutive up-day streak, % change 5/10/30/90d, dist from 52w high. All computed from yfinance adjusted closes — not LLM guesses.
↓ universe block (clean + extended pools with fundamentals) fed into LLM prompts
STEP 3 · THREE LLM LISTS
Claude generates 3 ranked candidate lists (run sequentially)
Each list excludes tickers already picked by prior lists — 30 unique tickers total
▾
📊 List 1 — Portfolio Fit
  • Knows current holdings
  • Knows sector weights (HHI)
  • Picks to complement existing exposure
  • Won't push any sector above 50%
👤 List 2 — Profile Fit
  • Knows user profile only (risk, horizon)
  • Treats portfolio as blank slate
  • High risk → conviction growth names
  • Excludes List 1 tickers
🌍 List 3 — Market Picks
  • No portfolio/profile context
  • Pure merit ranking
  • ≥3 non-US or non-tech names
  • Excludes Lists 1 & 2 tickers
ETF rule: For broad growth themes (AI, semis) → prefer ETF over stacking single names. For defensive/low-growth sectors → prefer a high-growth single name. Never recommend two ETFs tracking the same index.
Cash sizing: Max per ticker = cash / 5, capped at ₪25,000. Total across all picks ≤ available cash.
↓ LLM output enriched with deterministic yfinance data
STEP 4 · MOMENTUM POST-CHECK
Overwrite LLM guesses with real data, enforce signal vocabulary
4 signal values only — no HOLD, AVOID, SELL in opportunity lists
▾
After the LLM picks tickers, momentum-check runs again and overwrites its guesses with verified yfinance data. Signals are forced into exactly 4 values:
STRONG_BUY
Clean pool, exceptional thesis — deploy now
BUY
Clean pool, solid thesis — deploy now or on minor dips
WAIT-FOR-COOLING
Extended momentum — needs numeric trigger e.g. "RSI <60 for 3 days"
WAIT-FOR-CATALYST
Earnings within 14 days — wait for print, then re-evaluate
Override priority: parabolic slip-through → WAIT-FOR-COOLING · extended + BUY → WAIT-FOR-COOLING · earnings within 14d → WAIT-FOR-CATALYST · otherwise LLM signal stands
↓ evidence strength scored deterministically
STEP 5 · EVIDENCE STRENGTH SCORING
Score each pick's thesis quality: weak / moderate / strong
Deterministic regex — no LLM judgment, no manufactured confidence scores
▾
WEAK
0 inline citations in bull thesis OR bear threshold has no numeric value + operator. Example of a failing bear: "if growth slows" — no number, no operator.
MODERATE
1–2 inline citations in format (Source — YYYY-MM-DD) AND bear threshold contains a number + operator (below / above / < / > / drops / exceeds).
STRONG
3+ inline citations AND numeric bear threshold AND bull thesis contains a management quote keyword (said / stated / guided / CEO / CFO / commentary).
Why deterministic? An LLM asked "how confident are you?" manufactures precision. Regex counting citations is objective and auditable — the user can verify the sources themselves.
↓ final validation pass
STEP 6 · VALIDATION & OUTPUT
Dedup, ETF overlap check, write opportunities.json
30 unique tickers across 3 lists — no repeats, no overlapping ETFs
▾
🔍
Deduplication Any ticker appearing in more than one list is flagged with _duplicate_of. Lists run sequentially so each excludes prior tickers — this is a safety net.
📦
ETF Family Check Known ETF families (semis, S&P 500, EM, gold, bitcoin…) are looked up in a hardcoded dict. Two ETFs in the same family across any list → warning appended to output.
💾
Output Written to research/daily/<date>/opportunities.json. Each item includes: ticker, signal, fit, bull_thesis (with citations), bear_threshold, catalyst, momentum_check, evidence_strength, max_invest_ils, entry_quality.
⚡
Cost Phase 1 ≈ $2–4, ~5 min. Phase 2 (full bull/bear/manager per ticker) is opt-in: ~$30–50, ~25 min.
